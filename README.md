StudentHub

StudentHub is an educational web application developed as a diploma project at the Technical University of Sofia.

The application is designed to support the learning process by providing separate functionality for students, teachers and administrators.

Features:
- Role-based access for students, teachers and administrators
- Course management
- Course chat for students
- Homework submission
- Public and private homework visibility
- Homework grading
- Course lecture management

Technologies:
- PHP
- PostgreSQL
- JavaScript
- HTML
- CSS
- AJAX

Project Structure:

The application provides different functionality based on the user's role:

- Students – access courses, use course chat, submit homework and view grades
- Teachers – manage courses, students, lectures and homework
- Administrators – manage users and courses

Security:

The project includes basic security practices such as:

- Password hashing and verification
- Session-based authentication
- Parameterized database queries
- HTML output escaping

Academic Project:

This project was developed as part of my Bachelor's degree in Informatics and Software Sciences at the Technical University of Sofia.
